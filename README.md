# Word-Frequency-Tracker-in-Sports-Articles
A sports article word frequency analysis and visualization project using R, RStudio and Shiny Dashboard.

## Project Description
The Word Frequency Tracker in Sports Articles is a text analysis and visualization project that identifies frequently used words and patterns in sports-related articles.

The project analyzes articles from cricket, football, tennis, and basketball using text preprocessing and word frequency analysis.

## Technologies Used
- R Programming
- RStudio
- IBM Watson Studio
- Shiny Dashboard
- tidytext
- ggplot2
- wordcloud
- DT

## Project Modules
1. Data Collection Module
2. Data Cleaning Module
3. Data Preparation and Tokenization Module
4. Word Frequency and Text Analysis Module
5. Visualization Module
6. Article Exploration Module
7. Insight and Reporting Module

## Features
- Upload TXT and CSV files
- Text preprocessing and stopword removal
- Word frequency analysis
- Word frequency table
- Donut chart visualization
- Word cloud generation
- Bigram analysis
- Download results as CSV, PNG, and PDF

## How to Run
1. Install R and RStudio.
2. Install the required R packages.
3. Open the `app.R` file in RStudio.
4. Click **Run App**.
5. Upload a TXT or CSV sports article file.
6. Explore the word frequency results and visualizations.
